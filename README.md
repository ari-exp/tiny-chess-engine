A 4 KB Python chess engine for the make.fun tiny-chess-01 bounty: 0x88 board, negamax alpha-beta with a transposition table, quiescence, null-move pruning, check extension and late move reductions, capped at 120,000 nodes per move. Round-4 entry, trial-0 Elo 1,099.

## Run it

```sh
MAKEFUN_ENV_URL=<game-server-url> python3 main.py
```
